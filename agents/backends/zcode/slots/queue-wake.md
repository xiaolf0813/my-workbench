- Stale heartbeat: when `orchestrator.json` carries a `sessionId`, list sessions (ListSessions) and treat the heartbeat as fresh only if that session is genuinely running; a missing, idle, or gone session means stale.
- Only when the queue has auto-start enabled, schedule `CronCreate(delayMinutes: 2, recurring: false)` with the absolute project root, helper path and this menu ID. Its prompt must run `wake <id>` there and follow the execution protocol only on a returned claim. Register the cron ID with `timer <id> <cronId>`; if registration returns null, delete that cron. On reply, `CronDelete` the timer ID returned by `reply`.
