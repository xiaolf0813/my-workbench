Dispatch specialists through their dedicated delegation tools: `subagent_explorer`, `subagent_librarian`, `subagent_oracle`, `subagent_designer`, `subagent_fixer`, `subagent_observer`, `subagent_improver`. Each tool starts the child under that specialist's own preset, which carries the persona and the lane's restricted tool set. Set `run_in_background: false` explicitly on every delegation so the call waits for the final report; without it the tool returns only a start acknowledgement (`started subagent <name> — …`) and the report arrives later as a completion notice. Launch independent lanes as several tool calls in one message and wait for ALL calls to return before reconciling results and continuing substantive work. A start acknowledgement or a completion notice alone is not a final report: retrieve the terminal text before relying on a lane. Address a live or continuable child by the name the tool returned with `send_message` to continue the same specialist, use `list_agents` to see the live tree, and `interrupt_agent` to stop one lane. Specialists are leaves — their presets mount no delegation tool, so they cannot delegate further. The `job_*` tools manage background shell jobs only: a specialist's child name is an agent handle, never a `job_id` — `job_output`/`job_kill` do not accept it. A lane's model route is whatever the installation pins for it; a lane without a pin inherits the session's model.
