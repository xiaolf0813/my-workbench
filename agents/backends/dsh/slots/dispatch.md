Dispatch specialists through their dedicated delegation tools: `subagent_explorer`, `subagent_librarian`, `subagent_sentinel`, `subagent_designer`, `subagent_fixer`, `subagent_observer`, `subagent_improver`. Each tool carries its own specialist's prompt. Launch independent lanes as several tool calls in one message — they run in the background in parallel — and reconcile when their completion notices arrive. A call answers with a durable child id, which is that specialist's session handle: address it with `send_message` to continue the same specialist, `list_agents` to see the live tree, `interrupt_agent` to stop one lane. Specialists are leaves — their tool sets are restricted, so they cannot delegate further. The `job_*` tools manage background shell jobs only: a specialist's durable child id is an agent handle, never a `job_id` — `job_output`/`job_kill` do not accept it.
